So far the local conditional distributions were given. Usually they must be learned from data.

::: {#def-bn-parameters .definition name="Parameters, parameter sharing"}

The *parameters* $\theta$ of a Bayesian network are its local conditional distributions. With *parameter sharing*, there is a set $D$ of distribution types and each variable $X_i$ is generated by one type $d_i\in D$:

$$
P(X_1=x_1,\dots,X_n=x_n;\theta)=\prod_{i=1}^np_{d_i}\bigl(x_i\mid x_{\text{Parents}(i)}\bigr),\qquad\theta=\{p_d:d\in D\}.
$$

The *learning task* takes training examples, each a full assignment to all variables, and outputs $\theta$.

:::

Two users' ratings $R_1,R_2$ of a film of genre $G$ can each have their own $p_{R_1}(r\mid g)$, $p_{R_2}(r\mid g)$, or share one $p_R(r\mid g)$. In a hidden Markov model one $p_{\text{trans}}$ and one $p_{\text{emit}}$ serve every time step. Sharing means fewer parameters and so fewer examples needed; separate distributions are more flexible. Inference only reads the local distributions, so sharing does not matter there; learning writes them, so it does.

::: {#def-count-normalize .definition name="Count and normalize"}

For each type $d$, parent values $u$ and value $x$, let $\text{count}_d(u,x)$ be the number of pairs (example, variable $X_i$ with $d_i=d$) in which $x_{\text{Parents}(i)}=u$ and $x_i=x$. The *count-and-normalize* estimate is

$$
\hat p_d(x\mid u)=\frac{\text{count}_d(u,x)}{\sum_{x'}\text{count}_d(u,x')}.
$$

:::

```{=latex}
\begin{algorithm}
\caption{Count and normalize}
\begin{algorithmic}
\INPUT Training examples (full assignments), graph, types $d_i$
\OUTPUT Estimates $\hat p_d(x\mid u)$
\STATE $\text{count}_d(u,x)\gets0$ for all $d,u,x$
\FOR{each example $x$ and each variable $i$}
    \STATE $\text{count}_{d_i}(x_{\text{Parents}(i)},x_i)\gets\text{count}_{d_i}(x_{\text{Parents}(i)},x_i)+1$
\ENDFOR
\STATE $\hat p_d(x\mid u)\gets\text{count}_d(u,x)/\sum_{x'}\text{count}_d(u,x')$ for all $d,u,x$
\RETURN $\hat p$
\end{algorithmic}
\end{algorithm}
```

::: {#exm-count-normalize .example name="Genre and rating"}

With $P(G=g,R=r)=p_G(g)\,p_R(r\mid g)$ and training examples (drama, $4$), (drama, $5$), (comedy, $5$): $\hat p_G(\text{drama})=\tfrac23$, $\hat p_G(\text{comedy})=\tfrac13$, $\hat p_R(4\mid\text{drama})=\hat p_R(5\mid\text{drama})=\tfrac12$ and $\hat p_R(5\mid\text{comedy})=1$. To estimate $p_R(\cdot\mid g)$, each example only matters through its $(g,r)$: the other variables are ignored.

:::

Count and normalize on the data of @exm-count-normalize: count each local assignment, then normalize within each parent value.

:::

::: {#thm-count-normalize-mle .theorem name="Count and normalize is maximum likelihood"}

The count-and-normalize estimate maximizes the log-likelihood $\sum_{x\in\mathcal D}\log P(X=x;\theta)$ of the training data $\mathcal D$.

:::

::: {.proof}

1. Taking logarithms of the product in @def-bn-parameters and collecting equal terms,
$$
\sum_{x\in\mathcal D}\log P(X=x;\theta)=\sum_{d}\sum_{u}\sum_{x}\text{count}_d(u,x)\,\log p_d(x\mid u).
$$

2. Each distribution $p_d(\cdot\mid u)$ appears only in its own inner sum, so the maximization splits into one problem per pair $(d,u)$: maximize $\sum_xc(x)\log q(x)$ over distributions $q$, where $c(x)=\text{count}_d(u,x)$.

3. Let $N=\sum_xc(x)>0$ and $\hat q(x)=c(x)/N$. Then $\sum_xc(x)\log q(x)=-N\,H(\hat q,q)$, the cross entropy of @def-cross-entropy scaled by $-N$. By Gibbs' inequality (@thm-gibbs-inequality) this is largest exactly when $q=\hat q$. (If $N=0$ the pair $(d,u)$ never occurs and any $q$ is optimal.)

:::

The maximum likelihood estimate has a closed form, so no iterative optimization is needed.

::: {#def-laplace-smoothing .definition name="Laplace smoothing"}

*Laplace smoothing* with parameter $\lambda>0$ adds $\lambda$ to every count before normalizing:

$$
\hat p_d(x\mid u)=\frac{\text{count}_d(u,x)+\lambda}{\sum_{x'}\bigl(\text{count}_d(u,x')+\lambda\bigr)}.
$$

:::

With few data, maximum likelihood *overfits*: a value never seen gets probability $0$ (in @exm-count-normalize, $\hat p_R(2\mid\text{drama})=0$, which we do not believe). Smoothing prevents zeros. As $\lambda\to0$ it gives back the maximum likelihood estimate and as $\lambda\to\infty$ the uniform distribution; for fixed $\lambda$, its effect is washed out as the counts grow. With $\lambda=1$ and five possible ratings, $\hat p_R(4\mid\text{drama})=\frac{1+1}{2+5}=\frac27$ and $\hat p_R(2\mid\text{drama})=\frac17$.
