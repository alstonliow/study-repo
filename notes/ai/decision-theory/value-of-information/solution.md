1. **(1) and (2).** A decision network needs $A$ as an action node, an acyclic graph, and a utility node without children (@def-decision-network). (1) has exactly the dependencies described. (2) also lets $U$ depend on $S$; a utility table whose values do not change with $S$ represents Lexy's indifference, so (2) can represent her decision too, with a needlessly large table. (3) gives the utility node a child and contains the cycle $B\to I\to U\to S\to B$. In (4), $A$ is a chance node, so it is not a choice.
2. **Prior Sampling and Inference by Enumeration.** Enumeration computes any conditional probability exactly (@def-probabilistic-inference). From prior samples one estimates $P(F,O,c)$ and $P(c)$ by counting and divides (equivalently, rejection sampling uses the same samples). The forward algorithm and particle filtering are for hidden Markov models (@thm-forward-algorithm), which this network is not.
3. **Always true.** $U$ depends on $C$ only through $F$, so once $F$ is known, $C$ changes nothing: $\mathrm{MEU}(f,c)=\mathrm{MEU}(f)$, hence $\mathrm{VPI}(F,C)=\mathrm{VPI}(F)$. By order-independence and non-negativity (@thm-vpi-properties), $\mathrm{VPI}(F,C)=\mathrm{VPI}(C)+\sum_cP(c)\mathrm{VPI}(F\mid c)\ge\mathrm{VPI}(C)$.
4. **Never true.** $V$ affects $U$ only through $O$, so given $O$ it is worthless: $\mathrm{VPI}(V\mid O)=0$. By order-independence, $\mathrm{VPI}(V,O)=\mathrm{VPI}(V)+\mathrm{VPI}(O\mid V)\ge\mathrm{VPI}(O\mid V)$, so the left side, $\mathrm{VPI}(O\mid V)+0$, is at most the right side and never strictly larger. (Here $\mathrm{VPI}(O\mid V)$ means the expected value over the outcomes of $V$.)
5. **The first,** $\max_a\sum_f\sum_oP(f,o\mid c')U(f,o,a)=\mathrm{MEU}(c')$. The utility depends on $A$, $O$ and $F$, so the second formula, which drops $O$, has the wrong utility; the last two average over values $c$ that are no longer uncertain (and, as written, do not even use $c$ inside), whereas after observing $c'$ only its own maximum expected utility matters. Here $P(f,o\mid c')=P(f\mid c')P(o)$, since $O$ is independent of $C$.
