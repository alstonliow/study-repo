**Conditioning**

In class, we found the condition number of $f(x)=Ax$, in the $L_2$ norm, to be $\|A\|_2\|x\|_2/\|Ax\|_2$ for some $A\in\mathbb{C}^{m\times n}$ and $x\in\mathbb{C}^n$. Instead, compute the condition number of $g(A)=Ax$, using any convenient choice of norm (e.g. the Frobenius norm for the input matrices $A$).
