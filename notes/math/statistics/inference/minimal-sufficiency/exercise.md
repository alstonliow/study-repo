::: {.problem #prob-camib-sts-1-q11 origin="external" source="camib-sts-1-q11"}
For some $n\ge3$, let $\varepsilon_1,\dots,\varepsilon_n\overset{\text{iid}}{\sim}N(0,1)$, set $X_1=\varepsilon_1$ and $X_i=\theta X_{i-1}+(1-\theta^2)^{1/2}\varepsilon_i$ for $i=2,\dots,n$ and some $\theta\in(-1,1)$. Find a sufficient statistic for $\theta$ that takes values in a subset of $\mathbb R^3$.
:::
