A system of linear *equations* $Ax=b$ has no solution exactly when some combination of the equations reads $0=c$ with $c\ne0$. The same holds for linear *inequalities*, with nonnegative multipliers: infeasibility always has a short certificate.

::: {#thm-theorem-of-alternatives .theorem name="Theorem of the alternatives"}

For $A\in\mathbb R^{m\times n}$ and $b\in\mathbb R^m$, exactly one of the following holds:

1. there is $x\in\mathbb R^n$ with $Ax\le b$;
2. there is $y\in\mathbb R^m$ with
$$y\ge0,\qquad A^{\mathsf T}y=0,\qquad b^{\mathsf T}y<0.$$

:::

::: {.proof}

1. *Not both.* If $Ax\le b$ and $y$ is as in 2, then $0>b^{\mathsf T}y\ge y^{\mathsf T}Ax=(A^{\mathsf T}y)^{\mathsf T}x=0$, using $y\ge0$ in the middle step. This is impossible.

2. *At least one.* Suppose $Ax\le b$ has no solution. Eliminate $x_1,\dots,x_n$ one after another by Fourier–Motzkin (@def-fourier-motzkin). By @thm-fourier-motzkin each projection is empty exactly when the system before it is, so the final system, which has no variables, has no solution.

3. A system without variables consists of rows $0\le c_i$; it has no solution only if some $c_i<0$.

4. Every row produced by elimination is a nonnegative combination of the rows of the original system. So the row $0\le c_i$ is $y^{\mathsf T}(Ax)\le y^{\mathsf T}b$ for some $y\ge0$ with $A^{\mathsf T}y=0$ (all coefficients vanish) and $b^{\mathsf T}y=c_i<0$.

:::

::: {#lem-farkas .lemma name="Farkas' lemma"}

For $A\in\mathbb R^{m\times n}$ and $b\in\mathbb R^m$, exactly one of the following holds:

1. there is $x\in\mathbb R^n$ with $Ax=b$ and $x\ge0$;
2. there is $y\in\mathbb R^m$ with
$$A^{\mathsf T}y\ge0,\qquad b^{\mathsf T}y<0.$$

:::

Farkas' lemma for $A=(a_1\ a_2)$: the vector $b$ is not a nonnegative combination of the columns. The vector $y$ has $a_1^{\mathsf T}y>0$, $a_2^{\mathsf T}y>0$ but $b^{\mathsf T}y<0$; the dashed line $y^{\mathsf T}x=0$ separates $b$ from the cone.

:::

The lemma follows from @thm-theorem-of-alternatives by writing $Ax=b$, $x\ge0$ as the inequalities $Ax\le b$, $-Ax\le-b$, $-x\le0$ (exercise). Geometrically: either $b$ lies in the cone generated by the columns of $A$, or a hyperplane through the origin separates $b$ from that cone (@thm-separating-hyperplane).

::: {#exm-farkas-certificate .example name="A certificate of infeasibility"}

The system $x_1+x_2\le1$, $-x_1\le-1$, $-x_2\le-1$ (that is, $x_1,x_2\ge1$ and $x_1+x_2\le1$) has no solution. The multipliers $y=(1,1,1)\ge0$ give $A^{\mathsf T}y=(1-1,\ 1-1)=(0,0)$ and $b^{\mathsf T}y=1-1-1=-1<0$: adding the three inequalities yields $0\le-1$.

:::

::: {#rmk-farkas-lemma-1 .remark name="Mixed systems"}

The same argument applies to systems mixing inequalities and equalities: write each equality as two inequalities. The multipliers of an inequality are then $\ge0$, while the multiplier of an equality, the difference of two nonnegative numbers, is free. This form is used in the proof of strong duality (@thm-strong-duality).

:::
