A solution of a $2\times2$ system is a curve in the plane. Drawing many of them gives the *phase portrait*, and for a linear system its shape is decided by two numbers: the trace and the determinant.

::: {#def-phase-portrait .definition name="Phase plane, trajectory, phase portrait"}
For $\mathbf x'=A\mathbf x$ with $\mathbf x=(x,y)$, the *phase plane* is the $xy$-plane. A solution $t\mapsto\mathbf x(t)$ traces a *trajectory* in it, oriented by increasing $t$. The *phase portrait* is a sketch of representative trajectories. The origin is a *critical point*: the constant solution $\mathbf x=\mathbf0$.
:::

::: {#def-linear-critical-point-types .definition name="Types of critical point"}
Let $A$ be real $2\times2$ with $\det A\neq0$ and eigenvalues $\lambda_1,\lambda_2$. The origin is a

- *saddle* if $\lambda_1<0<\lambda_2$ (always unstable);
- *node* if $\lambda_1,\lambda_2$ are real with the same sign (stable if negative, unstable if positive); *defective* or *star* if they are equal;
- *spiral* if $\lambda=a\pm i\omega$ with $a\neq0$ (stable if $a<0$);
- *center* if $\lambda=\pm i\omega$: closed orbits, neutrally stable.
:::

::: {#thm-trace-determinant-classification .theorem name="Trace–determinant classification"}
Let $T=\operatorname{tr}A$ and $\Delta=\det A\neq0$. The eigenvalues are the roots of $\lambda^2-T\lambda+\Delta$, and the origin is

1. a saddle if $\Delta<0$;
2. a node if $\Delta>0$ and $T^2\ge4\Delta$;
3. a spiral if $\Delta>0$, $T^2<4\Delta$ and $T\neq0$; a center if $\Delta>0$ and $T=0$.

When $\Delta>0$ it is stable exactly when $T<0$.
:::

::: {.proof}
1. The characteristic polynomial of a $2\times2$ matrix is $\lambda^2-T\lambda+\Delta$, since $\lambda_1+\lambda_2=T$ and $\lambda_1\lambda_2=\Delta$ (@thm-trace-determinant-eigenvalues).

2. If $\Delta<0$ the product of the eigenvalues is negative, so they are real with opposite signs.

3. If $\Delta>0$ and the discriminant $T^2-4\Delta\ge0$, they are real with positive product, hence of equal sign, the sign of $T$.

4. If $T^2-4\Delta<0$ they are $\tfrac T2\pm i\omega$, with real part $T/2$: a spiral if $T\neq0$ and a center if $T=0$.

5. In every case with $\Delta>0$, the sign of the real parts is the sign of $T$, so the solutions decay exactly when $T<0$.
:::
