For a polynomial input the response is again a polynomial of the same degree, provided the operator does not kill constants. Its coefficients are found by solving a triangular system.

::: {#thm-undetermined-coefficients .theorem name="Polynomial input"}
Let $q$ be a polynomial of degree $n$ and $p(0)\neq0$. Then $p(D)y=q$ has exactly one polynomial solution, and it has degree $n$.
:::

::: {.proof}
1. Let $V$ be the space of polynomials of degree at most $n$; $p(D)$ maps $V$ to itself, since derivatives lower degree.

2. On the basis $t^n,t^{n-1},\dots,1$ the matrix of $p(D)$ is triangular: $p(D)t^k=a_0t^k+(\text{lower powers})$, with $a_0=p(0)$.

3. All diagonal entries equal $p(0)\neq0$, so the map is invertible on $V$: exactly one $y\in V$ has $p(D)y=q$.

4. Its leading coefficient is the leading coefficient of $q$ divided by $p(0)$, so it has degree exactly $n$.
:::

::: {#exm-undetermined-coefficients .example name="A quadratic input"}
Solve $y''+2y'+3y=t^2+1$ with $y=at^2+bt+c$.

1. $y''+2y'+3y=3at^2+(4a+3b)t+(2a+2b+3c)$.
2. Comparing coefficients: $3a=1$, $4a+3b=0$, $2a+2b+3c=1$.
3. Back-substitution: $a=\tfrac13$, $b=-\tfrac49$, $c=\tfrac{11}{27}$, so $y_p=\tfrac13t^2-\tfrac49t+\tfrac{11}{27}$.
:::

Solutions of $y''+2y'+3y=t^2+1$ with different initial values approach the polynomial solution $y_p$ (thick) found by undetermined coefficients.

:::

::: {#rmk-undetermined-coefficients-1 .remark name="When $p(0)=0$"}
If $p(s)=s^kp_1(s)$ with $p_1(0)\neq0$, then $p(D)y=p_1(D)\,D^ky$. First solve $p_1(D)w=q$ by the theorem, then integrate $w$ $k$ times: the solution is a polynomial of degree $n+k$. For example $y''+y'=1$ has no constant solution but has $y=t$.
:::

::: {#prp-exponential-times-polynomial .proposition name="Exponential times polynomial"}
For input $e^{rt}q(t)$ with $q$ a polynomial and $p(r)\neq0$, there is a solution $y=e^{rt}u(t)$ with $u$ a polynomial of the same degree as $q$, where $p(D+r)u=q$.
:::

::: {.proof}
1. By the exponential shift rule (@prp-operator-rules), $p(D)(e^{rt}u)=e^{rt}p(D+r)u$.

2. The polynomial $\tilde p(s)=p(s+r)$ has $\tilde p(0)=p(r)\neq0$, so @thm-undetermined-coefficients gives a polynomial $u$ of the degree of $q$ with $\tilde p(D)u=q$.
:::
