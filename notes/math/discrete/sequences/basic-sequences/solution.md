In each case the sequence starts at $n = 1$.

(a) $a_1 = 1$, $a_n = a_{n-1} + 1$.

(b) $a_1 = -2$, $a_n = a_{n-1} - 2$.

(c) $a_1 = 1$, $a_n = a_{n-1} + 2n - 1$, since $n^2 - (n-1)^2 = 2n-1$.

(d) $a_1 = 1$, $a_n = a_{n-1} + n$.

(e) $a_1 = 1$, $a_n = a_{n-1} + \frac1n$.
:::
