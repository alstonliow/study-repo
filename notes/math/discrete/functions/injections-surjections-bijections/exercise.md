::: {.problem #prob-functions-08 origin="external" source="fit1058-cn-2.19-q8"}
A *bitstring* is a member of $\{0,1\}^*$.

(a) Give a bijection from $\{0,1\}^*$ to $\mathbb{N}$.

Let $\{0,1\}^{*+}$ denote the set of all finite nonempty tuples of
bitstrings, e.g. $(011,1,10001)$, $(10,10,10,10)$, $(\epsilon,1011)$,
$(1010010001)$.

(b) (Challenge) Give a bijection from $\{0,1\}^{*+}$ to $\{0,1\}^*$.

::: {.problem #prob-mit6042f10-6-q2 origin="external" source="mit6042f10-6-q2"}
Every function has some subset of these properties:

injective, surjective, bijective

Determine the properties of the functions below, and briefly explain your reasoning.

(a) The function $f: \mathbb{R} \to \mathbb{R}$ defined by $f(x) = x\sin(x)$.

(b) The function $f: \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 99x^{99}$.

(c) The function $f: \mathbb{R} \to \mathbb{R}$ defined by $\tan^{-1}(x)$.

(d) The function $f: \mathbb{N} \to \mathbb{N}$ defined by $f(x) =$ the number of numbers that divide $x$. For example, $f(6) = 4$ because 1, 2, 3, 6 all divide 6. Note: We define here the set $\mathbb{N}$ to be the set of all positive integers ($1, 2, \ldots$).
:::
