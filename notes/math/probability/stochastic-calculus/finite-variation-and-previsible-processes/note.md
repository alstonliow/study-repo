Throughout, $(\Omega,\mathcal F,(\mathcal F_t)_{t\ge0},\Pr)$ is a filtered probability space (@def-continuous-filtration).

::: {#def-finite-variation-process .definition name="Finite variation process"}

A *càdlàg adapted process* is a map $X:\Omega\times[0,\infty)\to\mathbb R$ with càdlàg paths and $X_t\in\mathcal F_t$. A *finite variation process* is a càdlàg adapted process $A$ all of whose paths have finite variation. Its *total variation process* is $V_t=\int_0^t|dA_s|$.

:::

::: {#prp-total-variation-process .proposition name="The total variation process"}

$V$ is càdlàg, adapted, increasing and of finite variation.

:::

::: {.proof}

Only adaptedness needs proof. For nested subdivisions $0=t_0^{(m)}<\dots<t_{n_m}^{(m)}=t$ with mesh $\to0$, $V_t=|A_0|+\lim_m\sum_i|A_{t_i^{(m)}}-A_{t_{i-1}^{(m)}}|$ is a limit of $\mathcal F_t$-measurable variables.

:::

::: {#def-previsible .definition name="Previsible σ-algebra, simple process"}

Let $\Pi$ be the family of sets $E\times(s,t]$ with $E\in\mathcal F_s$, $s<t$, and let the *previsible σ-algebra* $\mathcal P$ be the σ-algebra on $\Omega\times[0,\infty)$ generated by $\Pi$. A process is *previsible* if it is $\mathcal P$-measurable. A *simple process*, written $H\in\mathcal E$, has the form
$$H_t(\omega)=\sum_{i=1}^nH_{i-1}(\omega)\mathbf 1_{(t_{i-1},t_i]}(t),\qquad H_{i-1}\in\mathcal F_{t_{i-1}}\ \text{bounded},\ 0=t_0<\dots<t_n.$$

:::

Roughly, a previsible event is one that can be foreseen an arbitrarily short time before it happens.

::: {#prp-left-continuous-previsible .proposition name="Left-continuous adapted processes are previsible"}

Simple processes, and limits of them, are previsible. If $X$ is càdlàg adapted then $H_t=X_{t-}$ is previsible; in particular continuous adapted processes are previsible. Every previsible $H$ has $H_t\in\mathcal F_{t-}=\sigma(\mathcal F_s:s<t)$.

:::

::: {.proof}

For left-continuous adapted $H$ put
$$H^n_t=\Big(\sum_{i\ge1}H_{(i-1)2^{-n}}\mathbf 1_{((i-1)2^{-n},i2^{-n}]}(t)\Big)\wedge n,$$
a simple-type process (the truncation keeps it bounded; the sum is locally finite). By left-continuity $H^n_t\to H_t$ for every $t$, hence $H$ is previsible.

:::

::: {#exm-previsible-examples .example name="Brownian motion versus the Poisson process"}

Brownian motion is previsible since it is continuous. A Poisson process $N$ is càdlàg but not previsible: its jump at time $t$ is not determined by $\mathcal F_{t-}$, so $N_t\notin\mathcal F_{t-}$.

:::

:::

::: {#prp-integral-against-fv .proposition name="Integrating a previsible process against a finite variation process"}

Let $A$ be a finite variation process and $H$ previsible with $\int_0^t|H_s|\,|dA_s|<\infty$ for all $(\omega,t)$. Then $H\cdot A$ is a finite variation process.

:::

::: {.proof}

The càdlàg and finite variation properties come from the deterministic theory; only adaptedness of $H\cdot A$ is new. Let $\mathcal V$ be the set of bounded $H$ for which $H\cdot A$ is adapted.

1. If $H=\mathbf 1_E\mathbf 1_{(u,v]}$ with $E\in\mathcal F_u$, then $(H\cdot A)_t=\mathbf 1_E(A_{t\wedge v}-A_{t\wedge u})\in\mathcal F_t$. So $\mathbf 1_F\in\mathcal V$ for $F\in\Pi$, and $1\in\mathcal V$.

2. $\mathcal V$ is a vector space closed under bounded monotone limits (monotone convergence for the integral).

3. $\Pi$ is a π-system generating $\mathcal P$, so by the monotone class theorem $\mathcal V$ contains all bounded previsible $H$. Unbounded $H$ are limits of $H\mathbf 1_{|H|\le n}$ by dominated convergence.

:::

So against finite variation integrators, integration is pathwise Lebesgue–Stieltjes integration and enjoys dominated convergence. A Brownian motion has infinite variation, which is why the next notes build a different integral for martingale integrators.
