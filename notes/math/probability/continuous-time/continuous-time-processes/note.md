With time in $[0,\infty)$ one family $(X_t)_{t\ge0}$ of random variables is not enough: for a random time $T$, the variable $X_T(\omega)=X_{T(\omega)}(\omega)$ need not be measurable, because $\mathcal B[0,\infty)$ is far from the power set of $\mathbb N$ that made discrete time easy. We therefore ask the paths $t\mapsto X_t(\omega)$ to be regular.

::: {#def-continuous-time-process .definition name="Continuous-time process, cadlag"}

A *continuous-time process* is a family $(X_t)_{t\ge0}$ of random variables. A function $x:[0,\infty)\to\mathbb R$ is *cadlag* (continue à droite, limite à gauche) if $x_s\to x_t$ as $s\downarrow t$ and $\lim_{s\uparrow t}x_s$ exists for all $t$. A process is *continuous* (resp. *cadlag*) if every path is. Let $C([0,\infty),\mathbb R)\subseteq D([0,\infty),\mathbb R)$ be the spaces of continuous, resp. cadlag, paths, each with the σ-algebra generated by the coordinate maps $x\mapsto x_s$; a continuous (cadlag) process is a random variable with values in it.

:::

::: {#def-finite-dimensional-distribution .definition name="Finite-dimensional distributions"}

For $0\le t_1<\dots<t_n$, the *finite-dimensional distribution* of $X$ is the law $\mu_{t_1,\dots,t_n}$ of $(X_{t_1},\dots,X_{t_n})$ on $\mathbb R^n$.

:::

The cylinder sets $\{(X_{t_1},\dots,X_{t_n})\in A\}$ form a π-system generating the σ-algebra, so *the finite-dimensional distributions determine the law of $X$*. For a continuous process, a dense set $I\subseteq[0,\infty)$ of times already suffices: $(X_t)_{t\ge0}$ is determined by $(X_t)_{t\in I}$ by continuity.

::: {#def-version .definition name="Version"}

A process $(Y_t)$ is a *version* of $(X_t)$ if $\Pr(Y_t=X_t)=1$ for each fixed $t$ (not the same as $\Pr(\forall t:\ Y_t=X_t)=1$).

:::

::: {#exm-version-not-continuous .example name="A version with worse paths"}

Let $X_t\equiv0$ and $U$ uniform on $[0,1]$, $Y_t=\mathbf 1_{\{t=U\}}$. For each $t$, $\Pr(Y_t=X_t)=\Pr(U\ne t)=1$, so $Y$ is a version of $X$; but $X$ is continuous and $Y$ is not (every path has a jump at $U$).

:::

When can random variables $(\rho_t)_{t\in I}$ given on a dense set be extended to a continuous process? Not always, but a Hölder condition in $L^p$ is enough.

::: {#thm-kolmogorov-continuity-criterion .theorem name="Kolmogorov's continuity criterion"}

Let $I\subseteq[0,1]$ be dense and $(\rho_t)_{t\in I}$ random variables with, for some $p>1$ and $\beta>1/p$,

$$
\|\rho_t-\rho_s\|_p\le C|t-s|^\beta\qquad(s,t\in I).
$$

Then there is a continuous process $(X_t)_{t\in[0,1]}$ with $X_t=\rho_t$ almost surely for $t\in I$, and for every $\alpha\in[0,\beta-1/p)$ a random variable $K_\alpha\in L^p$ with $|X_s-X_t|\le K_\alpha|s-t|^\alpha$ for all $s,t$.

:::

::: {.proof}

1. Let $D_n=\{k2^{-n}\}\cap[0,1]$ and $D=\bigcup_nD_n$, dense. We may assume $D\subseteq I$: for $t\in D$ define $\rho_t$ as the $L^p$-limit of $\rho_s$, $s\to t$, $s\in I$ ($L^p$ is complete); the inequality survives limits.

2. Put $K_n=\sup_{t\in D_n}|\rho_{t+2^{-n}}-\rho_t|$. Then $E[K_n^p]\le\sum_{t\in D_n}E|\rho_{t+2^{-n}}-\rho_t|^p\le2^n\,C^p2^{-n\beta p}$, so $\|K_n\|_p\le C\,2^{n(1/p-\beta)}$.

3. For $s<t$ in $D$ choose $m$ with $2^{-(m+1)}<t-s\le2^{-m}$ and a point $u=k2^{-(m+1)}$ with $s<u<t$ (so $u-s,t-u<2^{-m}$). Expanding $u-s$ and $t-u$ in binary digits beyond position $m+1$ and chaining dyadic increments gives $|\rho_s-\rho_t|\le2\sum_{n>m}K_n$.

4. Hence $\dfrac{|\rho_s-\rho_t|}{|s-t|^\alpha}\le2\sum_{n>m}2^{(m+1)\alpha}K_n\le2\sum_{n\ge0}2^{(n+1)\alpha}K_n$ (using $m+1\le n$). Define $K_\alpha=2\sum_{n\ge0}2^{(n+1)\alpha}K_n$. By Minkowski, $\|K_\alpha\|_p\le2\sum_n2^{(n+1)\alpha}\|K_n\|_p\le C'\sum_n2^{n(\alpha+1/p-\beta)}<\infty$ because $\alpha<\beta-1/p$.

5. So almost surely $|\rho_s-\rho_t|\le K_\alpha|s-t|^\alpha$ on $D$, and $\rho$ extends uniquely to a continuous (indeed $\alpha$-Hölder) function; set $X_t=\lim_{q\to t,\,q\in D}\rho_q$ where $K_\alpha<\infty$ for all admissible $\alpha$, and $X_t=0$ elsewhere. For $t\in I$, continuity in $L^p$ of $\rho$ shows $X_t=\rho_t$ a.s.

:::

The proof chains dyadic increments: any increment is bounded by the sum of the maximal increments $K_n$ over all finer levels, and $\sum 2^{n\alpha}K_n$ converges in $L^p$ exactly when $\alpha<\beta-1/p$.
