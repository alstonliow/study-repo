Ergodic theory studies time averages $\frac1n\big(f(x)+f(\Theta x)+\dots+f(\Theta^{n-1}x)\big)$ along the orbit of a measure-preserving map. Throughout, $(E,\mathcal E,\mu)$ is a measure space.

::: {#def-measure-preserving .definition name="Measure-preserving map, invariant sets, ergodicity"}

A measurable $\Theta:E\to E$ is *measure-preserving* if $\mu(\Theta^{-1}(A))=\mu(A)$ for all $A\in\mathcal E$. A set $A\in\mathcal E$ is *invariant* if $\Theta^{-1}(A)=A$, and a measurable $f$ is *invariant* if $f\circ\Theta=f$. The invariant sets form a σ-algebra $\mathcal E_\Theta$; $f$ is invariant exactly when it is $\mathcal E_\Theta$-measurable. $\Theta$ is *ergodic* if every invariant set $A$ has $\mu(A)=0$ or $\mu(A^c)=0$.

:::

For a measure-preserving $\Theta$ and integrable $f$, $\mu(f\circ\Theta)=\mu(f)$: this is the image-measure formula, $\mu\circ\Theta^{-1}=\mu$. An invariant function of an ergodic map is a.e. constant. We write

$$
S_n(f)=f+f\circ\Theta+\dots+f\circ\Theta^{n-1},\qquad S_0=0 .
$$

::: {#exm-rotations-doubling .example name="Rotations and the doubling map"}

On $[0,1)$ with Lebesgue measure, the rotation $\Theta_a(x)=x+a\bmod1$ and the doubling map $\tau(x)=2x\bmod1$ are measure-preserving: $\Theta_a^{-1}$ of an interval is one or two intervals of the same total length, and $\tau^{-1}([s,t))=[\frac s2,\frac t2)\cup[\frac{s+1}2,\frac{t+1}2)$ has the same length as $[s,t)$; uniqueness of extension then covers all Borel sets. The rotation is ergodic exactly when $a$ is irrational, and the doubling map is ergodic.

:::

::: {#prp-bernoulli-shift-ergodic .proposition name="Bernoulli shifts are ergodic"}

Let $m$ be a Borel probability measure on $\mathbb R$. On $E=\mathbb R^{\mathbb N}$ with the σ-algebra generated by the coordinates $X_n(x)=x_n$, let $\mu$ be the law of a sequence of independent random variables with law $m$ (@thm-iid-sequence-exists). It is determined by $\mu(A_1\times\dots\times A_k\times\mathbb R\times\cdots)=\prod_{j\le k}m(A_j)$. The *shift* $\Theta(x_1,x_2,\dots)=(x_2,x_3,\dots)$ is measure-preserving and ergodic.

:::

::: {.proof}

1. $\Theta^{-1}(A_1\times\dots\times A_k\times\mathbb R\times\cdots)=\mathbb R\times A_1\times\dots\times A_k\times\cdots$ has the same measure. These cylinder sets form a generating π-system, so $\mu\circ\Theta^{-1}=\mu$ (@thm-uniqueness-of-extension).

2. Under $\mu$ the coordinates $X_n$ are independent with law $m$. If $A$ is invariant, then $A=\Theta^{-n}(A)$, and $\Theta^{-n}(A)\in\sigma(X_{n+1},X_{n+2},\dots)$ because $X_k\circ\Theta^n=X_{k+n}$. So $A$ is a tail event, and $\mu(A)\in\{0,1\}$ by Kolmogorov's zero-one law (@thm-kolmogorov-zero-one).

:::

::: {#lem-maximal-ergodic .lemma name="Maximal ergodic lemma"}

Let $\Theta$ be measure-preserving and $f$ integrable, and let $S^*=\sup_{n\ge0}S_n(f)$. Then

$$
\int_{\{S^*>0\}}f\,d\mu\ge0 .
$$

:::

::: {.proof}

1. Let $S_n^*=\max_{0\le m\le n}S_m$ and $A_n=\{S_n^*>0\}$. $S_n^*$ is integrable, being bounded by $\sum_{k<n}|f|\circ\Theta^k$.

2. For $1\le m\le n$, $S_m=f+S_{m-1}\circ\Theta\le f+S_n^*\circ\Theta$. On $A_n$ the maximum defining $S_n^*$ is attained at some $m\ge1$ (because $S_0=0$), so $S_n^*\le f+S_n^*\circ\Theta$ on $A_n$.

3. Off $A_n$, $S_n^*=0\le S_n^*\circ\Theta$ (note $S_n^*\ge S_0=0$ everywhere).

4. Integrate and use $\mu(S_n^*\circ\Theta)=\mu(S_n^*)$:
$$\mu(S_n^*)\le\int_{A_n}f\,d\mu+\int_ES_n^*\circ\Theta\,d\mu=\int_{A_n}f\,d\mu+\mu(S_n^*).$$
Subtracting the finite $\mu(S_n^*)$ gives $\int_{A_n}f\ge0$.

5. $A_n\uparrow\{S^*>0\}$, and $|f\mathbf 1_{A_n}|\le|f|$, so dominated convergence finishes the proof.

:::

::: {#thm-birkhoff-ergodic .theorem name="Birkhoff's ergodic theorem"}

Let $\mu$ be σ-finite, $\Theta$ measure-preserving and $f$ integrable. There is an invariant $\bar f$ with $\mu(|\bar f|)\le\mu(|f|)$ and

$$
\frac{S_n(f)}{n}\to\bar f\qquad\text{almost everywhere.}
$$

If $\Theta$ is ergodic, $\bar f$ is a.e. constant.

:::

::: {.proof}

1. $S_n\circ\Theta=S_{n+1}-f$, so $\limsup_nS_n/n$ and $\liminf_nS_n/n$ are invariant (the term $f/n\to0$).

2. For rationals $a<b$ let $D=\{\liminf S_n/n<a<b<\limsup S_n/n\}$, an invariant set. The limit fails to exist exactly on the countable union of these sets, so it suffices to show $\mu(D)=0$.

3. Let $B\subseteq D$ with $\mu(B)<\infty$ and $g=(f-b\mathbf 1_B)\mathbf 1_D$, which is integrable. Because $D$ is invariant, $\mathbf 1_D\circ\Theta^k=\mathbf 1_D$, so $S_n(g)=\mathbf 1_D\big(S_n(f)-bS_n(\mathbf 1_B)\big)\ge\mathbf 1_D\big(S_n(f)-nb\big)$.

4. On $D$, $S_n(f)>nb$ for some $n$, so $\{S^*(g)>0\}=D$. The maximal ergodic lemma gives $0\le\int_Dg=\int_Df-b\mu(B)$.

5. By σ-finiteness choose such $B$ increasing to $D$: $b\mu(D)\le\int_Df\,d\mu$. The same argument with $-f$ and $-a$ gives $-a\mu(D)\le-\int_Df\,d\mu$, i.e. $\int_Df\le a\mu(D)$.

6. If $b>0$, the first inequality shows $\mu(D)\le\mu(|f|)/b<\infty$; if $b\le0$ then $a<0$ and the second does. Combining, $b\mu(D)\le\int_Df\le a\mu(D)$ with $\mu(D)$ finite and $a<b$, so $\mu(D)=0$.

7. Let $\bar f=\lim S_n/n$ where the limit exists and is finite, and $0$ elsewhere. It is invariant by step 1. By Fatou and $\mu(|S_n|)\le n\mu(|f|)$, $\mu(|\bar f|)\le\liminf\mu(|S_n|/n)\le\mu(|f|)$; in particular $\bar f$ is a.e. finite, so the limit is finite a.e. In the ergodic case an invariant function is a.e. constant.

:::

::: {#thm-von-neumann-ergodic .theorem name="von Neumann's ergodic theorem"}

Let $\mu$ be finite, $\Theta$ measure-preserving, $1\le p<\infty$ and $f\in L^p$. Then $S_n(f)/n\to\bar f$ in $L^p$, with $\bar f$ as in Birkhoff's theorem.

:::

::: {.proof}

1. $\|f\circ\Theta^k\|_p=\|f\|_p$ by measure preservation, so $\|S_n(f)/n\|_p\le\|f\|_p$ by Minkowski. Also $f\in L^1$, $\mu$ being finite, so $\bar f$ exists.

2. Given $\varepsilon>0$, choose $M$ with $g=(f\vee(-M))\wedge M$ satisfying $\|f-g\|_p\le\varepsilon$ (dominated convergence as $M\to\infty$).

3. $|S_n(g)/n|\le M$ and $S_n(g)/n\to\bar g$ a.e., so $\|S_n(g)/n-\bar g\|_p\to0$ by bounded convergence on the finite measure space.

4. By Fatou, $\|\bar f-\bar g\|_p^p\le\liminf_n\|S_n(f-g)/n\|_p^p\le\varepsilon^p$, using that $S_n(f)/n-S_n(g)/n=S_n(f-g)/n\to\bar f-\bar g$ a.e.

5. Hence $\|S_n(f)/n-\bar f\|_p\le\|S_n(f-g)/n\|_p+\|S_n(g)/n-\bar g\|_p+\|\bar g-\bar f\|_p\le3\varepsilon$ for large $n$.

:::
