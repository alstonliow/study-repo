::: {.problem #prob-camii-pms-1-q7 origin="external" source="camii-pms-1-q7"}
Let $(A_n:n\in\mathbb N)$ be a sequence of events in a probability space. Show that the events $A_n$ are independent if and only if the σ-algebras $\sigma(A_n)=\{\emptyset,A_n,A_n^c,\Omega\}$ are independent.
:::

::: {.problem #prob-camii-pms-2-q4 origin="external" source="camii-pms-2-q4"}
Let $(A_n:n\in\mathbb N)$ be a sequence of events, with $\mathbb P(A_n)=1/n^2$ for all $n$. Set $X_n=n^2\mathbf 1_{A_n}-1$ and set $\bar X_n=(X_1+\dots+X_n)/n$. Show that $\mathbb E(\bar X_n)=0$ for all $n$, but that $\bar X_n\to-1$ almost surely as $n\to\infty$.
:::

::: {.problem #prob-camii-pms-2-q5 origin="external" source="camii-pms-2-q5"}
The zeta function is defined for $s>1$ by $\zeta(s)=\sum_{n=1}^\infty n^{-s}$. Let $X$ and $Y$ be independent random variables with
$$\mathbb P(X=n)=\mathbb P(Y=n)=n^{-s}/\zeta(s).$$
Write $A_n$ for the event that $n$ divides $X$. Show that the events $(A_p:p\text{ prime})$ are independent and deduce Euler's formula
$$\frac1{\zeta(s)}=\prod_p\Big(1-\frac1{p^s}\Big).$$
Show also that $\mathbb P(X\text{ is square-free})=1/\zeta(2s)$. Write $H$ for the highest common factor of $X$ and $Y$. Show finally that $\mathbb P(H=n)=n^{-2s}/\zeta(2s)$.
:::

::: {.problem #prob-camii-pms-2-q6 origin="external" source="camii-pms-2-q6"}
Let $(X_n:n\in\mathbb N)$ be independent $N(0,1)$ random variables. Prove that
$$\limsup_n\frac{X_n}{\sqrt{2\log n}}=1\quad\text{a.s.}$$
:::
