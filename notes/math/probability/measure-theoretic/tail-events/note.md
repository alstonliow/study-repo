Some events do not depend on any finite number of the variables in a sequence: whether $\sum_nX_n$ converges, or whether $X_n>1$ infinitely often. For independent variables such events are trivial.

::: {#def-tail-sigma-algebra .definition name="Tail σ-algebra"}

For random variables $X_1,X_2,\dots$ let $\mathcal T_n=\sigma(X_{n+1},X_{n+2},\dots)$. The *tail σ-algebra* is

$$
\mathcal T=\bigcap_{n\ge1}\mathcal T_n .
$$

Its members are *tail events*; a $\mathcal T$-measurable random variable is a *tail random variable*.

:::

::: {#exm-tail-events .example name="Tail events and tail variables"}

With $S_n=X_1+\dots+X_n$:

1. $\{\sum_nX_n\text{ converges}\}$ is a tail event, because convergence does not change when finitely many terms are dropped: for each $m$ it is the convergence set of $\sum_{n>m}X_n$, which is $\mathcal T_m$-measurable (@prp-measurable-closure).
2. $\limsup_nS_n/n$ and $\liminf_nS_n/n$ are tail random variables: $S_n/n$ and $(X_{m+1}+\dots+X_n)/n$ differ by $S_m/n\to0$.
3. $\{X_n>1\text{ infinitely often}\}=\limsup_n\{X_n>1\}$ is a tail event. On the other hand $\{S_n>0\text{ for all }n\}$ is not, in general.

:::

::: {#thm-kolmogorov-zero-one .theorem name="Kolmogorov's zero-one law"}

If $X_1,X_2,\dots$ are independent, then every tail event has probability $0$ or $1$, and every tail random variable $Y:\Omega\to[-\infty,\infty]$ is almost surely constant.

:::

::: {.proof}

1. Let $\mathcal F_n=\sigma(X_1,\dots,X_n)$. By @cor-independence-grouping, $\mathcal F_n$ and $\mathcal T_n$ are independent. Since $\mathcal T\subseteq\mathcal T_n$, $\mathcal F_n$ and $\mathcal T$ are independent for every $n$.

2. $\bigcup_n\mathcal F_n$ is a π-system (the $\mathcal F_n$ increase) containing $\Omega$. It is independent of the π-system $\mathcal T$, so by @thm-independence-pi-systems $\sigma\big(\bigcup_n\mathcal F_n\big)=\sigma(X_1,X_2,\dots)$ is independent of $\mathcal T$.

3. But $\mathcal T\subseteq\sigma(X_1,X_2,\dots)$. So every $A\in\mathcal T$ is independent of itself: $\Pr(A)=\Pr(A\cap A)=\Pr(A)^2$, whence $\Pr(A)\in\{0,1\}$.

4. For a tail random variable $Y$, each $\{Y\le y\}$ is a tail event. The function $y\mapsto\Pr(Y\le y)$ is non-decreasing with values in $\{0,1\}$; let $c=\inf\{y:\ \Pr(Y\le y)=1\}\in[-\infty,\infty]$. Then $\Pr(Y\le y)=0$ for $y<c$ and $=1$ for $y>c$, and continuity of $\Pr$ along $y\downarrow c$ and $y\uparrow c$ gives $\Pr(Y=c)=1$.

:::

$\mathcal T_n$ is generated by the variables after time $n$; the tail σ-algebra is their intersection. For independent variables each $\mathcal F_n$ is independent of $\mathcal T_n$, hence of the tail, which forces tail events to be independent of themselves.

:::

::: {#rmk-tail-events-1 .remark name="What the law does not say"}

The zero-one law says that $\Pr(\sum_nX_n\text{ converges})$ is $0$ or $1$, and that $\limsup_nS_n/n$ is a.s. a constant, but not which value. The Borel–Cantelli lemmas, the strong law (@sec-math-probability-measure-theoretic-strong-law-of-large-numbers) and the ergodic theorem (@sec-math-probability-measure-theoretic-ergodic-theorems) identify it. For example, for independent signs $X_n=\pm1$ with probability $\frac12$ each, the random series $\sum_nX_n/n$ converges almost surely, while $\sum_nX_n/\sqrt n$ diverges almost surely (Kolmogorov's three-series theorem, not proved in these notes).

:::
