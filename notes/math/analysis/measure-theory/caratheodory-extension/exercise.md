Let $(E,\mathcal E,\mu)$ be a measure space. Call a subset $N\subseteq E$ null if $N\subseteq B$ for some $B\in\mathcal E$ with $\mu(B)=0$. Write $\mathcal N$ for the set of null sets. Prove that the set of subsets $\mathcal E^\mu=\{A\cup N:\ A\in\mathcal E,\ N\in\mathcal N\}$ is a σ-algebra and show that $\mu$ has a well-defined and countably additive extension to $\mathcal E^\mu$ given by $\mu(A\cup N)=\mu(A)$. We call $\mathcal E^\mu$ the completion of $\mathcal E$ with respect to $\mu$. Suppose now that $\mathcal E$ is σ-finite and write $\mu^*$ for the outer measure associated to $\mu$, as in the proof of Carathéodory's Extension Theorem. Show that $\mathcal E^\mu$ is exactly the set of $\mu^*$-measurable sets.
