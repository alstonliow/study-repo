::: {.problem #prob-camii-pms-1-q3 origin="external" source="camii-pms-1-q3"}
Show that a countably additive set function on a ring is additive, increasing and countably subadditive.
:::

::: {.problem #prob-camii-pms-1-q5 origin="external" source="camii-pms-1-q5"}
Let $\mu$ be a finite-valued additive set function on a ring $\mathcal A$. Show that $\mu$ is countably additive if and only if the following condition holds: for any decreasing sequence $(A_n:n\in\mathbb N)$ of sets in $\mathcal A$, with $\bigcap_nA_n=\emptyset$, we have $\mu(A_n)\to0$.
:::

::: {.problem #prob-camii-pms-1-q6 origin="external" source="camii-pms-1-q6"}
Let $(E,\mathcal E,\mu)$ be a finite measure space. Show that, for any sequence of sets $(A_n:n\in\mathbb N)$ in $\mathcal E$,
$$\mu(\liminf A_n)\le\liminf\mu(A_n)\le\limsup\mu(A_n)\le\mu(\limsup A_n).$$
Show that the first inequality remains true without the assumption that $\mu(E)<\infty$, but that the last inequality may then be false.
:::
