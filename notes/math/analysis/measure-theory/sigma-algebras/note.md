A measure assigns a size to sets. It cannot in general be defined on every subset (@thm-vitali-set), so we first fix a family of sets that is closed under the operations we need: complements and countable unions.

::: {#def-sigma-algebra .definition name="σ-algebra, measurable space"}

Let $E$ be a set. A collection $\mathcal E$ of subsets of $E$ is a *σ-algebra* on $E$ if

$$
\emptyset\in\mathcal E,\qquad A\in\mathcal E\ \Rightarrow\ A^c\in\mathcal E,\qquad A_1,A_2,\dots\in\mathcal E\ \Rightarrow\ \bigcup_{n}A_n\in\mathcal E .
$$

The pair $(E,\mathcal E)$ is a *measurable space* and the members of $\mathcal E$ are the *measurable sets*.

:::

By De Morgan's laws a σ-algebra is also closed under countable intersections, and it contains $E=\emptyset^c$ and all differences $B\setminus A=B\cap A^c$.

::: {#prp-sigma-algebra-intersection .proposition name="Intersections of σ-algebras"}

The intersection of any non-empty family of σ-algebras on $E$ is a σ-algebra on $E$. Consequently, for every collection $\mathcal A$ of subsets of $E$ there is a smallest σ-algebra containing $\mathcal A$,

$$
\sigma(\mathcal A)=\bigcap\{\mathcal E:\ \mathcal E\text{ is a σ-algebra on }E,\ \mathcal A\subseteq\mathcal E\},
$$

called the σ-algebra *generated* by $\mathcal A$.

:::

::: {.proof}

1. Let $\mathcal E^*$ be the intersection of the family. Each member contains $\emptyset$, so $\emptyset\in\mathcal E^*$.

2. If $A\in\mathcal E^*$ then $A$ lies in every member, hence so does $A^c$; thus $A^c\in\mathcal E^*$.

3. Countable unions are handled the same way: a sequence in $\mathcal E^*$ lies in every member, so its union does.

4. The power set of $E$ is a σ-algebra containing $\mathcal A$, so the family in the formula for $\sigma(\mathcal A)$ is non-empty. Its intersection is a σ-algebra by steps 1–3, contains $\mathcal A$, and is contained in every σ-algebra containing $\mathcal A$.

:::

A union of two σ-algebras need not be one: on $E=\{1,2,3\}$ the σ-algebras $\{\emptyset,\{1\},\{2,3\},E\}$ and $\{\emptyset,\{2\},\{1,3\},E\}$ have a union that contains $\{1\}$ and $\{2\}$ but not $\{1,2\}$.

::: {#def-borel-sigma-algebra .definition name="Borel σ-algebra"}

Let $E$ be a topological space. Its *Borel σ-algebra* is the σ-algebra generated by the open sets,

$$
\mathcal B(E)=\sigma(\{U\subseteq E:\ U\text{ open}\}).
$$

We write $\mathcal B=\mathcal B(\mathbb R)$. A measure on $(E,\mathcal B(E))$ is a *Borel measure*.

:::

Every open or closed set, every countable intersection of open sets and every countable union of closed sets is Borel. On $\mathbb R$ the open intervals already generate $\mathcal B$, because every open set is a countable union of open intervals with rational end points; so do the half-open intervals $(a,b]$, since $(a,b]=\bigcap_n(a,b+\tfrac1n)$ and $(a,b)=\bigcup_n(a,b-\tfrac1n]$.

## π-systems and d-systems

Checking a property for every set of a σ-algebra is usually hard; checking it for a simple generating family is easy. The bridge is Dynkin's lemma.

::: {#def-pi-d-system .definition name="π-system, d-system"}

A collection $\mathcal A$ of subsets of $E$ is a *π-system* if $\emptyset\in\mathcal A$ and $A\cap B\in\mathcal A$ whenever $A,B\in\mathcal A$.

It is a *d-system* (Dynkin system) if

$$
E\in\mathcal A,\qquad A,B\in\mathcal A,\ A\subseteq B\ \Rightarrow\ B\setminus A\in\mathcal A,\qquad A_1\subseteq A_2\subseteq\cdots\in\mathcal A\ \Rightarrow\ \bigcup_nA_n\in\mathcal A .
$$

:::

The intervals $(a,b]$ together with $\emptyset$ form a π-system on $\mathbb R$; so do the half-lines $(-\infty,b]$ with $\emptyset$.

::: {#prp-pi-and-d-is-sigma .proposition name="A π-system that is a d-system is a σ-algebra"}

A collection $\mathcal A$ of subsets of $E$ is a σ-algebra if and only if it is both a π-system and a d-system.

:::

::: {.proof}

1. A σ-algebra contains $\emptyset$ and $E$, is closed under finite intersections and differences, and under all countable unions. So it is both.

2. Conversely let $\mathcal A$ be both. It contains $\emptyset$. For $A\in\mathcal A$, $A^c=E\setminus A\in\mathcal A$ because $A\subseteq E\in\mathcal A$.

3. For $A,B\in\mathcal A$: $A\cup B=(A^c\cap B^c)^c\in\mathcal A$ by step 2 and the π-property. By induction $\mathcal A$ is closed under finite unions.

4. For a sequence $A_1,A_2,\dots\in\mathcal A$ put $B_n=A_1\cup\dots\cup A_n\in\mathcal A$. The $B_n$ increase, so $\bigcup_nA_n=\bigcup_nB_n\in\mathcal A$.

:::

::: {#lem-dynkin .lemma name="Dynkin's π-system lemma"}

Let $\mathcal A$ be a π-system. Then every d-system containing $\mathcal A$ also contains $\sigma(\mathcal A)$.

:::

::: {.proof}

1. Let $\mathcal D$ be the intersection of all d-systems containing $\mathcal A$. It is again a d-system (the checks are as in @prp-sigma-algebra-intersection), it contains $\mathcal A$, and it lies in every d-system containing $\mathcal A$. By @prp-pi-and-d-is-sigma it is enough to show that $\mathcal D$ is a π-system: then $\mathcal D$ is a σ-algebra containing $\mathcal A$, so $\sigma(\mathcal A)\subseteq\mathcal D$.

2. Let $\mathcal D'=\{B\in\mathcal D:\ B\cap A\in\mathcal D\text{ for all }A\in\mathcal A\}$. It contains $\mathcal A$, since $\mathcal A$ is a π-system.

3. $\mathcal D'$ is a d-system. It contains $E$. If $B\subseteq C$ are in $\mathcal D'$ and $A\in\mathcal A$, then $(C\setminus B)\cap A=(C\cap A)\setminus(B\cap A)$ is a difference of nested members of $\mathcal D$, so lies in $\mathcal D$. If $B_n\uparrow B$ with $B_n\in\mathcal D'$, then $B_n\cap A\uparrow B\cap A$, so $B\cap A\in\mathcal D$.

4. By minimality $\mathcal D'=\mathcal D$: every $B\in\mathcal D$ meets every $A\in\mathcal A$ inside $\mathcal D$.

5. Now let $\mathcal D''=\{B\in\mathcal D:\ B\cap C\in\mathcal D\text{ for all }C\in\mathcal D\}$. By step 4 it contains $\mathcal A$, and the argument of step 3, with $C\in\mathcal D$ in place of $A\in\mathcal A$, shows it is a d-system. So $\mathcal D''=\mathcal D$, which says that $\mathcal D$ is closed under intersections.

:::

A collection is a σ-algebra exactly when it is both a π-system and a d-system. Dynkin's lemma is used by checking a property on a π-system (such as the half-open intervals) and showing that the sets with the property form a d-system.

:::

::: {#def-ring-algebra .definition name="Ring and algebra of sets"}

A collection $\mathcal A$ of subsets of $E$ with $\emptyset\in\mathcal A$ is a *ring* if $A\cup B\in\mathcal A$ and $B\setminus A\in\mathcal A$ for all $A,B\in\mathcal A$. It is an *algebra* if instead $A\cup B\in\mathcal A$ and $A^c\in\mathcal A$ for all $A,B\in\mathcal A$.

:::

An algebra is a ring ($B\setminus A=(B^c\cup A)^c$), and a ring containing $E$ is an algebra. Rings are closed under finite intersections, since $A\cap B=A\setminus(A\setminus B)$. The finite disjoint unions of intervals $(a,b]$ form a ring on $\mathbb R$; it is the starting point for Lebesgue measure (@sec-math-analysis-measure-theory-lebesgue-measure).
