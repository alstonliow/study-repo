::: {.problem #prob-camii-pms-1-q1 origin="external" source="camii-pms-1-q1"}
Let $E$ be a set and let $\mathcal S$ be a set of σ-algebras on $E$. Define
$$\mathcal E^*=\{A\subseteq E:\ A\in\mathcal E\ \text{ for all }\ \mathcal E\in\mathcal S\}.$$
Show that $\mathcal E^*$ is a σ-algebra on $E$. Show, on the other hand, by example, that the union of two σ-algebras on the same set need not be a σ-algebra.
:::

::: {.problem #prob-camii-pms-1-q2 origin="external" source="camii-pms-1-q2"}
Show that the following sets of subsets of $\mathbb R$ all generate the same σ-algebra:
(a) $\{(a,b):\ a<b\}$, (b) $\{(a,b]:\ a<b\}$, (c) $\{(-\infty,b]:\ b\in\mathbb R\}$.
:::

Show that a π-system which is also a d-system is a σ-algebra.
