::: {.problem #prob-camii-lans-3-q1 origin="external" source="camii-lans-3-q1"}
Let $L$ be a closed subset of a normal topological space $K$. Show that any bounded continuous function $g:L\to\mathbb C$ extends to a bounded continuous function $f:K\to\mathbb C$ with $\|f\|_\infty=\|g\|_\infty$.
:::

::: {.problem #prob-camii-lans-3-q2 origin="external" source="camii-lans-3-q2"}
Let $L$ be a closed subset of a normal topological space $K$. Show that any (not necessarily bounded) continuous function $g:L\to\mathbb R$ extends to a continuous function $f:K\to\mathbb R$.
:::

::: {.problem #prob-camii-lans-3-q11 origin="external" source="camii-lans-3-q11"}
Let $S$ be a subset of a normal topological space $X$. Show that there is a continuous function $f:X\to\mathbb R$ such that $S=f^{-1}(0)$ if and only if $S$ is a closed $\mathcal G_\delta$ set.
:::

::: {.problem #prob-camii-lans-3-q12 origin="external" source="camii-lans-3-q12"}
A topological space is \emph{Lindel\"of} if every open cover has a countable subcover, and is \emph{regular} if for every closed subset $F$ and point $x\notin F$, there are disjoint open sets $U$ and $V$ with $x\in U$ and $F\subset V$. Prove that a regular Lindel\"of space is normal.
:::
