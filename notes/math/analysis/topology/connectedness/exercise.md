::: {.problem #prob-camib-ats-4-q6 origin="external" source="camib-ats-4-q6"}
Which of the following subsets of $\mathbb{R}^2$ with the Euclidean topology are connected? Which are path-connected? (And why?)

(a) $\{(x,y) \in \mathbb{R}^2 : \|(x,y) - (-1,0)\| \leqslant 1 \text{ or } \|(x,y) - (1,0)\| < 1\}$;

(b) $\{(x,y) \in \mathbb{R}^2 : x = 0 \text{ or } y = qx \text{ for } q \in \mathbb{Q}\}$;

(c) $\{(x,y) \in \mathbb{R}^2 : x = 0 \text{ or } y = qx \text{ for } q \in \mathbb{Q}\}\setminus\{(0,0)\}$;

(d) $S \subset \mathbb{R}^2$ any star-shaped domain, i.e. a set with the property that there is a point $x_0 \in S$ such that for all $x \in S$, the line segment between $x_0$ and $x$ is contained in $S$.
:::

::: {.problem #prob-camib-ats-4-q7 origin="external" source="camib-ats-4-q7"}
Let $K_1 \supset K_2 \supset K_3 \supset \cdots$ be a decreasing sequence of non-empty, connected, compact subsets of a Hausdorff space $X$. Let $K = \bigcap_{n=1}^\infty K_n$.

(a) Show that $K$ is non-empty.

(b) Show that $K$ is connected.

(c) Give an example with $X = \mathbb{R}^2$ to show that the conclusion of part (b) need not be true if $K_n$ are assumed to be "closed" instead of "compact".
:::

::: {.problem #prob-camib-ats-4-q8 origin="external" source="camib-ats-4-q8"}
Show that if $f : S^1 \to \mathbb{R}$ is continuous then there is an $x \in S^1$ such that $f(-x) = f(x)$. Deduce that at any point in time there are antipodal locations on the Earth's equator that have the same temperature.
:::

::: {.problem #prob-camib-ats-4-q9 origin="external" source="camib-ats-4-q9"}
($\star$) Let $f : \mathbb{R}^m \to \mathbb{R}^n$ be a function under which the image of each path-connected set is path-connected and the image of each compact set is compact. Show that $f$ is continuous.
:::
