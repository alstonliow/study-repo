::: {.problem #prob-camib-ats-2-q6 origin="external" source="camib-ats-2-q6"}
Which of the following functions $f : [0,\infty) \to \mathbb{R}$ are uniformly continuous?

(a) $f(x) = \inf\{|x - n^2| : n \in \mathbb{N}\}$;

(b) $f(x) = \sin x^2$;

(c) $f(x) = (\sin x^3)/(x^2 + 1)$.
:::

::: {.problem #prob-camib-ats-2-q7 origin="external" source="camib-ats-2-q7"}
Let $f : [0,\infty) \to [0,\infty)$ be uniformly continuous and such that $\int_0^\infty f(x)\,dx$ exists and is finite.

(a) Show that $\lim_{x\to\infty}f(x) = 0$.

(b) Is this still true if $f$ is only continuous? Give a proof or counterexample.
:::
