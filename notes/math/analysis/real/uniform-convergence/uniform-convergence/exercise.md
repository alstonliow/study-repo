::: {.problem #prob-camib-ats-1-q12 origin="external" source="camib-ats-1-q12"}
Which of the following sequences $(f_n)$ of functions converge uniformly on the set $X$? If it exists, what is their uniform limit?

(a) $f_n(x) = x^{2n}$ on $X = (0,1)$;

(b) $f_n(x) = xe^{-nx}$ on $X = [0,\infty)$;

(c) $f_n(x) = e^{-x}\sin(x/n)$ on $X = \mathbb{R}$.
:::

::: {.problem #prob-camib-ats-1-q13 origin="external" source="camib-ats-1-q13"}
($\star$) Let $(f_n)$ be a sequence of real-valued functions on a set $X$, which are pointwise bounded: $\sup_{n\in\mathbb{N}}|f_n(x)| \leq g(x) < \infty$ for a function $g$ on $X$.

(a) Let $X = \mathbb{N}$, show that $(f_n)$ has a convergent subsequence.

(b) If $X = \mathbb{R}$, does $(f_n)$ still have a convergent subsequence?
:::
