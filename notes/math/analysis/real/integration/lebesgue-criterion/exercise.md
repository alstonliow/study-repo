Let $f : [a,b] \to \mathbb{R}$ with $a \neq b$.

(a) For an interval $I \subset [a,b]$, define the *oscillation* of $f$ in $I$ by $\operatorname{osc}_I(f) = \sup_I f - \inf_I f$. Show that if $I' \subset I$ is an interval, then $\operatorname{osc}_{I'}(f) \leq \operatorname{osc}_I(f)$. Show that $U(f,\mathcal{P}) - L(f,\mathcal{P}) = \sum_{j=1}^n |I_j|\operatorname{osc}_{I_j}(f)$ for $I_j = [x_{j-1}, x_j]$ and $\mathcal{P} = x_0 < \cdots < x_n$.

(b) Show that, if $f$ is bounded and has discontinuities only in the set $\{d_1, \dots, d_k\} \subset (a,b)$, for some finite $k \in \mathbb{N}$, then $f$ is integrable.

(c) ($\star$) Show that, if $f$ is integrable, then $f$ has a point of continuity. Deduce that $f$ must have infinitely many points of continuity.
