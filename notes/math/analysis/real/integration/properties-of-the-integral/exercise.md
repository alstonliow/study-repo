::: {.problem #prob-cama1s-3-q10 origin="external" source="cama1s-3-q10"}
Give an example of an integrable function $f : [0,1] \to \mathbb{R}$ with $f \geqslant 0$, $\int_0^1 f = 0$, and $f(x) > 0$ for some value of $x$. Show that this cannot happen if $f$ is continuous.
:::

::: {.problem #prob-cama1s-4-q4 origin="external" source="cama1s-4-q4"}
Let $f : [a,b] \to \mathbb{R}$ be continuous and suppose that $\int_a^b f(x)g(x)\,dx = 0$ for every continuous function $g : [a,b] \to \mathbb{R}$ which vanishes near $a$ and $b$. Must $f$ vanish identically? [We say $g$ vanishes near $a$ and $b$ if there exists $\epsilon > 0$ such that $g(x) = 0$ for $x \notin (a + \epsilon, b - \epsilon)$.]
:::
