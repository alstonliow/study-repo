Handle sustained notes, using “where each foot is” (on an arrow or in the middle) as added state for suffix subproblems

*Note (these notes):* The setting is the fingering DP of @exm-piano-fingering applied to a dance game with four arrows: $F=2$ feet, and at most $T=2$ arrows to press at once. A *sustained* note asks for an arrow to be held down from one time step to a later one.
