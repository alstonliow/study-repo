<!-- Sipser 2.18; 18.404J PS1, read-and-solve problem (not handed in) -->
::: {.problem #prob-sipser3e-2-q18 origin="external" source="sipser3e-2-q18"}
a. Let $C$ be a context-free language and $R$ be a regular language. Prove that the language $C\cap R$ is context free.

b. Let $A=\{w\mid w\in\{\mathtt a,\mathtt b,\mathtt c\}^*\text{ and } w \text{ contains equal numbers of }\mathtt a\text{'s, }\mathtt b\text{'s, and }\mathtt c\text{'s}\}$. Use part (a) to show that $A$ is not a CFL.
:::

::: {.problem #prob-sipser3e-2-q32 origin="external" source="sipser3e-2-q32"}
Let $\Sigma=\{1,2,3,4\}$ and $C=\{w\in\Sigma^*\mid \text{in } w, \text{ the number of 1s equals the number of 2s, and the number of 3s equals the number of 4s}\}$. Show that $C$ is not context free.
:::
