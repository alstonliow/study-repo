## Grammars and derivations

::: {#def-cfg .definition name="Context-free grammar"}

A *context-free grammar* (CFG) is a 4-tuple $G=(V,\Sigma,R,S)$ of a finite set $V$ of *variables*, an alphabet $\Sigma$ of *terminals* disjoint from $V$, a finite set $R$ of *rules* $A\to u$ with $A\in V$ and $u\in(V\cup\Sigma)^*$, and a *start variable* $S\in V$. If $A\to u$ is a rule, then $vAw$ *yields* $vuw$, written $vAw\Rightarrow vuw$; $u\overset{*}{\Rightarrow}v$ means $v$ is obtained from $u$ by zero or more such steps, a *derivation*. The language of $G$ is

$$
L(G)=\{w\in\Sigma^*: S\overset{*}{\Rightarrow}w\},
$$

and a language is *context-free* (a CFL) if some CFG generates it.

:::

Rules with the same left side are combined with $\mid$. A derivation can be drawn as a *parse tree*: the root is $S$, each internal node is a variable whose children, left to right, are the right side of the rule applied, and the leaves read left to right give the derived string.

::: {#exm-cfg-examples .example name="Context-free grammars"}

1. $S\to 0S1\mid\varepsilon$ generates $\{0^k1^k: k\ge0\}$, which is not regular (@exm-0n1n-nonregular): $S\Rightarrow0S1\Rightarrow00S11\Rightarrow0011$.
2. $S\to SS\mid (S)\mid\varepsilon$ generates the balanced strings of parentheses.
3. The grammar $G_2$ with variables $E,T,F$ (expression, term, factor) and rules

$$
E\to E+T\mid T,\qquad T\to T\times F\mid F,\qquad F\to(E)\mid a
$$

generates arithmetic expressions in $a$, $+$, $\times$ and parentheses, and its parse trees respect precedence: in $a+a\times a$ the product is a subtree.

:::

## Ambiguity

::: {#def-ambiguous-grammar .definition name="Ambiguous grammar"}

A *leftmost derivation* always replaces the leftmost variable. A string $w$ is derived *ambiguously* in $G$ if it has two different leftmost derivations (equivalently, two different parse trees), and $G$ is *ambiguous* if it derives some string ambiguously.

:::

::: {#exm-ambiguous-grammar .example name="An ambiguous expression grammar"}

The grammar $E\to E+E\mid E\times E\mid(E)\mid a$ generates the same strings as $G_2$, but $a+a\times a$ has two parse trees: one with $+$ at the root (product first) and one with $\times$ at the root (sum first). $G_2$ is unambiguous. Some CFLs, such as $\{a^ib^jc^k: i=j \text{ or } j=k\}$, have only ambiguous grammars; they are *inherently ambiguous*.

:::

## Chomsky normal form

::: {#def-chomsky-normal-form .definition name="Chomsky normal form"}

A CFG is in *Chomsky normal form* if every rule has one of the forms

$$
A\to BC,\qquad A\to a,\qquad S\to\varepsilon,
$$

where $a$ is a terminal, $B,C$ are variables other than the start variable, and only the start variable may have an $\varepsilon$-rule.

:::

::: {#thm-chomsky-normal-form .theorem name="Every CFL has a grammar in Chomsky normal form"}

Every context-free language is generated by a grammar in Chomsky normal form. In such a grammar every derivation of a nonempty string $w$ has exactly $2|w|-1$ steps.

:::

::: {.proof}

1. *New start.* Add a start variable $S_0$ and the rule $S_0\to S$, so that the start variable never appears on a right side.

2. *Remove $\varepsilon$-rules.* For each rule $A\to\varepsilon$ with $A\ne S_0$, delete it, and for every occurrence of $A$ on a right side add a copy of that rule with this occurrence deleted ($R\to uAv$ gives $R\to uv$; a rule $R\to A$ gives $R\to\varepsilon$ unless that rule was already removed). Repeat until no such rule remains. The generated strings are the same, since each new rule shortcuts an $A$ that would have derived $\varepsilon$.

3. *Remove unit rules* $A\to B$: delete it, and for each rule $B\to u$ add $A\to u$ (unless it is a unit rule removed earlier). Repeat.

4. *Shorten and convert.* Replace $A\to u_1u_2\cdots u_k$ with $k\ge3$ by $A\to u_1A_1$, $A_1\to u_2A_2$, …, $A_{k-2}\to u_{k-1}u_k$ with new variables; then in each two-symbol right side replace a terminal $a$ by a new variable $U_a$ with $U_a\to a$.

5. *Count.* In Chomsky normal form a derivation of $w\ne\varepsilon$ uses $|w|-1$ rules $A\to BC$ (each increases the number of symbols by one, from $1$ to $|w|$) and $|w|$ rules $A\to a$ (one per terminal), so $2|w|-1$ steps.

:::
