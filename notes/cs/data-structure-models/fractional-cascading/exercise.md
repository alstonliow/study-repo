**Range tree construction.** Recall that in class we presented the range tree and the layered range tree for answering orthogonal range queries. However, we did not describe how to construct them efficiently.

1. Describe how to construct a $d$-dimensional range tree on $n$ given points in $O(n\lg^{d-1}n)$ time.
2. Describe how to construct a $d$-dimensional layered range tree on $n$ given points in $O(n\lg^{d-1}n)$ time.
:::
